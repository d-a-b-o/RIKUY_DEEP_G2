# Industrial Casting Product Defect Detection

Este proyecto implementa un modelo de Machine Learning / Computer Vision para la detección automática de defectos en piezas de fundición industrial. El objetivo es automatizar el control de calidad clasificando las imágenes en productos defectuosos o sin defectos, optimizando así los flujos de trabajo de inspección.

## 📊 Dataset

Los datos utilizados en este proyecto provienen del **"Real-life industrial dataset of casting product"**.
- **Autor original:** [Ravirajsinh Dabhi (ravirajsinh45)](https://www.kaggle.com/datasets/ravirajsinh45/real-life-industrial-dataset-of-casting-product)
- **Fuente:** Kaggle
